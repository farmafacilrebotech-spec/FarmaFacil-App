# Plantillas de material

Fondos corporativos definitivos (originales intactos en
`docs/qa/share/Referencias_Corporativas/Material_Publicitario/`). La app
superpone nombre, logo y QR. Zonas en `lib/pharmacies/pharmacy-qr-poster-layout.ts`.

- `cartel-acceso-qr-a5.png` — Plantilla 1 · Cartel acceso mostrador A5
  (1747×2481, 300 dpi). Solo hay zona QR: el original no tiene huecos de
  logo ni nombre.
- `flyer-acceso-qr-a6.png` — Plantilla 2 · Flyer A6 (4419×6250). Logo + nombre
  + QR. Se usa también en el pliego A4 de 10 flyers (2×2 por página, 3 páginas).
- `cartel-publicitario-a3.png` — Plantilla 3 · Cartel publicitario
  (3508×4961, nativo A3; A4 con las mismas zonas normalizadas). Los
  placeholders grises se tapan con relleno opaco antes de dibujar.
- `pharmacy-qr-a4.png` — arte antiguo (idéntico a `flyer-acceso-qr-a6.png`);
  ya no lo referencia la app, solo scripts de revisión antiguos.
